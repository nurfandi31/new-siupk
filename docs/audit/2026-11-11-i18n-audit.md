# Audit Internasionalisasi (i18n) UI — siupk Next 2026-11-11

## Latar Belakang

Aplikasi siupk Next sudah memiliki dua bahasa UI (Indonesia `id` dan Inggris
`en`), tetapi cakupannya belum merata: hanya sebagian kecil halaman Vue yang
memakai `t()`. Akibatnya, saat pengguna memilih English, banyak label, judul
kolom, tombol, dan placeholder tetap tampil dalam Bahasa Indonesia.

Audit ini memetakan dan membungkus teks UI statis agar dapat diterjemahkan,
**tanpa menyentuh data yang berasal dari database** (nama anggota, nominal,
nama lembaga, status dari server, dan sebagainya).

## Prinsip & Batasan

| Prinsip | Penjelasan |
|---|---|
| Sumber locale = Indonesia | `t('teks Indonesia')` mengembalikan teks asli saat locale `id`, dan kamus `en` saat locale `en`. |
| Hanya teks UI | Yang dibungkus hanya teks statis di template, atribut statis (placeholder, title, aria-label, dll.), dan properti objek label di `<script setup>`. |
| Data database tidak diterjemahkan | Semua `{{ ekspresi }}` yang berisi data server/DB dilewati. Hanya string literal di dalam ekspresi yang aman (mis. fallback `|| '—'`, ternary status) yang diterjemahkan. |
| Format uang tetap `id-ID` | Rupiah & parser input tidak diubah agar konsisten. Hanya **tanggal** yang mengikuti locale (`id-ID` / `en-GB`). |
| Konservatif | Teks yang terpecah oleh interpolasi atau bercampur elemen anak yang berisi teks tidak dipaksakan. |

## Arsitektur

- `resources/js/i18n/index.js`
  - `en` — kamus Inggris dengan key teks Indonesia.
  - `t(key, params)` — mendukung placeholder `:name` dan `{name}`.
  - `useI18n()` — `locale`, `locales`, `setLocale`, `toggleLocale`, `t`,
    `dateLocale`, `numberLocale`.
  - `dateLocale()` → `en-GB` / `id-ID`; `numberLocale()` → `en-US` / `id-ID`.
  - Locale disimpan di `localStorage` (`siupk-locale`).
- `resources/js/Components/AppLanguageSwitcher.vue`
  - Dropdown bahasa; setelah memilih bahasa, memicu
    `router.reload({ preserveScroll: true, preserveState: false })` agar label
    yang dihitung saat `setup` (kolom tabel, menu) ikut berubah.

## Pekerjaan pada Audit Ini

### 1. Perbaikan scanner (`scripts/i18n-scan.mjs`)

- **Komponen `<Link>` tidak lagi dianggap tag HTML void `link`.**
  Sebelumnya isi `<Link>` tidak pernah menjadi blok teks sehingga tombol
  "Kembali ke halaman masuk" di halaman auth tidak terbungkus.
- **Dukungan literal string di dalam mustache**:
  - `{{ 'Teks' }}`
  - `{{ kondisi ? 'A' : 'B' }}`
  - `{{ nilai || 'Default' }}`
  - Ekspresi yang memanggil fungsi (termasuk `t()`), memakai konkatenasi,
    template literal, atau akses indeks **dilewati**.
- **Aturan "mixed" lebih akurat**: teks hanya dilewati jika elemen anak
  benar-benar memiliki teks/interpolasi bermakna. Ikon dekoratif (mis.
  `<span class="dot">`) tidak lagi memblokir pembungkusan.
- Scanner bersifat idempoten dan aman dijalankan berulang.

### 2. Pembungkusan teks

- Seluruh 230 berkas `.vue` dipindai.
- **210 berkas** kini memakai `t()` dengan **±6.672 call site**.
- Teks dibungkus di template, atribut statis, dan objek label di script.

### 3. Kamus & terjemahan

- Kamus Inggris berisi **3.648 key** unik.
- Seluruh key `t()` yang dipakai aplikasi sudah tercakup (0 key hilang).
- Terjemahan mesin (Google Translate) dilengkapi **glosarium domain** dan
  koreksi manual, antara lain:
  - `Pokok` → Principal, `Jasa`/`Bunga` → Interest, `Pemanfaat` → Beneficiaries
  - `Pencairan` → Disbursement, `Angsuran` → Installment, `Tunggakan` → Arrears
  - `Simpanan` → Savings, `Plafon` → Limit, `Kolektibilitas` → Collectibility
  - `Sinkron` → Sync, `Cadangan` (instance WA) → Backup, `Tertinggal` → Missing
  - `S.d. Triwulan Berjalan` → Up to Current Quarter
- Koreksi konteks yang salah diterjemahkan mesin juga diterapkan (mis.
  `Flowers`→Interest, `Moon`→Month, `Tree`→Principal, `Ceiling`→Limit).

### 4. Format tanggal

- `Intl.DateTimeFormat('id-ID')`, `toLocaleDateString('id-ID')`, dan sejenisnya
  di **30 berkas** diubah memakai `dateLocale()` sehingga tanggal mengikuti
  bahasa aktif.
- Label bulan pada `usePeriodOptions`, `AppDatePicker`, dan peta kolektibilitas
  OJK dibungkus `t()`.

### 5. Pemilih bahasa

`AppLanguageSwitcher` tersedia di:

- `Layouts/AuthenticatedLayout.vue`, `AdminLayout.vue`,
  `TenantAdminLayout.vue`, `RegencyLayout.vue`, `ProvinceLayout.vue`
- `Pages/Home.vue`, `Components/PublicSiteHeader.vue`,
  `Pages/PublicSite/TenantHome.vue`
- Seluruh halaman auth: `Login.vue`, `UserLogin.vue`, `ForgotPassword.vue`,
  `ResetPassword.vue`, `VerifyOtp.vue`

## Sisa Pekerjaan Manual

Scanner masih melaporkan **428 kandidat manual** yang sengaja tidak diubah
otomatis:

| Alasan | Jumlah | Contoh |
|---|---:|---|
| `fragmented` — teks terpecah beberapa node dalam satu blok | 265 | `Total alokasi per anggota (` … `) melebihi plafon` |
| `interpolated` — kalimat bercampur nilai dinamis | 135 | `{{ n }} pinjaman aktif` |
| `mixed` — blok berisi anak dengan teks bermakna | 28 | `Halo, {{ nama }}` di dalam paragraf bercampur `<strong>` |

Kandidat ini aman dibiarkan dalam Bahasa Indonesia karena:
- menerjemahkan potongan kalimat akan menghasilkan tata bahasa Inggris yang
  rusak, dan
- menerjemahkan teks yang mengandung data berisiko mengubah nilai yang dikirim
  ke server.

Halaman dengan kandidat terbanyak: `Lending/Loans/Show.vue`,
`Admin/Migration/Index.vue`, `Accounting/Reports/YearEnd/ClosingJournal.vue`,
`Accounting/PeriodClose/Index.vue`, `Accounting/Journals/Index.vue`.

## Di Luar Cakupan (Out of Scope)

1. **Pesan backend (flash/validasi)** masih Bahasa Indonesia.
   - `lang/id` hanya berisi `validation.php`.
   - `lang/en` sudah memiliki `auth.php`, `pagination.php`, `passwords.php`,
     `validation.php`.
   - Pesan flash buatan controller/service belum memakai `__()`.
2. **Halaman error Blade** (`resources/views/errors/*.blade.php`, 12 berkas)
   masih teks statis Indonesia.
3. **Template PDF laporan** (`resources/views/reports`, ±150 berkas Blade)
   tetap Bahasa Indonesia sesuai dokumen resmi.
4. **Konten dari database**: nama anggota/lembaga/desa, nominal, status, nama
   role, dan teks yang dikirim server tidak diterjemahkan.
5. **Email/notifikasi WhatsApp** yang dirender server.
6. Nama brand (`siupk Next`, `BUMDesma`, `LKD`, `UPK`) dibiarkan apa adanya.

## Cara Menjalankan Ulang

```bash
# 1. Audit / bungkus otomatis teks statis
node scripts/i18n-scan.mjs
node scripts/i18n-scan.mjs --write            # terapkan
node scripts/i18n-scan.mjs --only=Pages/Auth  # subset

# 2. Daftar key yang belum ada di kamus
node scripts/i18n-extract.mjs

# 3. Terjemahkan key baru (butuh jaringan)
node scripts/i18n-translate.mjs

# 4. Tulis ke resources/js/i18n/index.js
node scripts/i18n-apply.mjs

# 5. Validasi build
npm run build
```

Laporan audit mentah: `storage/app/i18n-audit.json`
(`manualCandidates`, `missingKeysByFrequency`, `byFile`).

## Verifikasi

- `node scripts/i18n-scan.mjs` → **0 temuan otomatis tersisa**.
- `npm run build` → **sukses** (Vite, per 2026-11-11).
